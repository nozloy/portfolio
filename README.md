# Portfolio

Минималистичное портфолио в стиле terminal / developer workspace.

## Stack

- React 19 + TypeScript + Vite
- Motion — анимации
- Radix UI Dialog — доступный просмотр кейсов
- Lucide React — иконки
- Spotlight-паттерн в духе React Bits реализован локально без тяжёлого UI-kit

## Кейсы

11 исходных скриншотов сгруппированы по 6 проектам и собраны в оптимизированные WebP-превью:

- MyPicks / Находки — 3 экрана
- BattlePay — 2 экрана
- ГлавСИЗ — 3 экрана
- IrkutskCars38 — 1 экран
- Beauty Queen — 1 mobile экран
- Император — 1 mobile экран

## Запуск

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
```
